# pilot-opening-meeting-cut02-seedance20-4s-draft-v2-previz-only

パイロット冒頭CUT 2「前回の成果に戸惑う信者B」を、Seedance 2.0で試作する4秒・プレビズのみ版。

## v1からの変更

- 信者Bの手元にノートPCを追加。
- 信者B、パイプ椅子、PCを同じ中央軸へ配置。
- PCを画面下部中央へ収め、画面端から離した。
- カラー背景資料を添付対象から除外。
- 扉、スイッチ、東壁、窓の画角外配置をプロンプト本文で固定。
- 扉、スイッチ、信者B・椅子・PCの画面座標を固定。
- ノートPCの外装をマットなチャコールグレーへ固定し、全尺で色相・明度・材質を維持。
- 構図整合を画質、演技、口パク、装飾より上位の採用条件へ変更。

1. `01-cut02-two-beat-blocking-board-v7-pc-centered.png` — `BLK_1`

画像2枚。カラー背景資料と音声参照は未添付。

## プレビズの読み方

- 左パネル: Beat 01。信者Bが口を閉じ、短い戸惑いを見せる。
- 右パネル: Beat 02。同じ固定画角で質問を言い切る。
- 両パネルともPCは信者Bと椅子の中央軸上にあり、画面端へ寄らない。
- 扉は信者Bと同じ東壁の画面左。スイッチは扉と信者Bの間。
- 各16:9パネル内の目安は、扉の外接範囲が横5〜25%、スイッチ中心が横32%、信者B・椅子・PCの中心軸が横56%。
- 左右は別CUTではなく、CUT 2内の演技変化。
- 白黒マネキン、罫線、説明帯、灰色の仮表現は完成映像へ持ち込まない。

## 尺

- 4秒。Seedance 2.0の最短生成尺に合わせる。
- 冒頭の戸惑い: 約0.20秒。
- 暫定発話: 約0.20〜3.25秒。
- 言い切り後: 約0.75秒の編集用ハンドル。

実音声が提供されたら、無音区間と発話尺を再計測して更新する。

## 採用判定

- 扉、スイッチ、信者B、椅子、PC、机、壁の輪郭が全尺で同じ位置、縮尺、向きを保つこと。
- ノートPCが全尺で無地のマットなチャコールグレーを保つこと。
- 上記のいずれかが崩れた場合は、他の画質や演技が良くても不採用とする。

## 生成設定

- Seedance 2.0
- Reference-to-Video
- 1080p
- 16:9
- 4秒

生成画面側で指定し、プロンプト本文へ重複記載しない。
