# 真理の扉：専用 BGM

曲名：**The Word Behind the Eye**（管理用タイトル）

真理の扉のために新しく組んだ、歌詞のないオリジナルの短い楽曲です。既存曲、録音、配布サンプル、第三者の残響データは使っていません。Python の加算合成で、柔らかい鐘、母音を思わせる持続音、低音の脈動を作っています。持続音も実際の人声ではありません。

## 音楽

- 64 BPM、4/4、16 小節、60 秒。
- 基本の旋律は D5 → A4 → E5 → F5。高い鐘を詰め込みすぎず、音のない隙間も残しています。
- 1–4 小節：D minor(add9) / B♭maj9。柔らかい鐘と、明るさの残る静かな導入。
- 5–8 小節：旋律を再提示し、高音の小さな応答を追加。C(add9) で一度景色を開きます。
- 9–12 小節：G minor の低い旋律と B♭maj7(#11)。少しだけ視線を感じる響き。
- 13–16 小節：A7sus4(b9) の緊張から D minor(add9) へ戻り、冒頭に接続します。
- 激しい打楽器や大きな衝撃音は入れず、ミス時の目の効果音が前に出る余地を残しています。

## ファイル

- `truth-chamber-bgm.wav`：44.1 kHz / 16 bit / stereo の制作マスター。
- `truth-chamber-bgm.flac`：同じ PCM を無劣化で圧縮した、Web 用の第一候補。
- `truth-chamber-bgm.mp3`：192 kbps の互換用。エンコーダの遅延・パディング情報を保持。
- `generate_truth_bgm.py`：音符、音色、構成、残響、書き出し、検証を含む再現用コード。
- `truth-bgm-validation.json`：実際のデコード結果、音量、ピーク、ループ境界の数値。

FLAC を先に指定し、MP3 を予備にしてください。サイト側の音の許可、ミュート、音量スライダーを引き続き使います。WAV マスターは再生成できるため、サイトへの配信やリポジトリへの収録は必須ではありません。

MP3 のみ、圧縮エンコーダがファイル両端に作る小さな乱れを抑えるため、先頭と末尾のそれぞれ 16 ミリ秒に滑らかな音量窓をかけています。無音区間や時間の追加はありません。FLAC と WAV はこの処理をせず、円環の余韻をそのまま保持します。

## ループと音量

音符の余韻と自作のホール残響を 60 秒の円環に重ね、最後の音を途中で切らずに冒頭へ戻しています。音源全体をフェードアウトする処理や、末尾の無音はありません。波形の値と傾きの境界差を通常のサンプル差と比較し、デコード後の WAV / FLAC / MP3 を検証します。

マスターは EBU R128 の約 −19 LUFS を目標に、ピークを抑えた線形ゲインで調整します。リミッターで押しつぶす処理はありません。確定した測定値は JSON を参照してください。HTML の audio 要素によるループ再開のタイミング自体はブラウザの実装にも依存します。MP3 のコンテナ表示時間はエンコーダのパディングで 60 秒を少し超えることがありますが、デコード後の実音は 60 秒です。

この納品では数値検証を実施しています。人による試聴済みとはしていません。

## 再生成

Python 3、numpy、scipy、soundfile、および PATH 上の ffmpeg / ffprobe が必要です。

```text
python generate_truth_bgm.py --output ./rendered
```

乱数シードは `20260906` 固定です。同一の依存環境では同じスコアと音を生成できます。音色や音符を変えたときは、書き出しに続いて音量とループ境界の検証も再実行されます。
