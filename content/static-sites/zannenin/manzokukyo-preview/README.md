# 満足教ティザー・入口デザイン仮案

- 確認URL: `/zannenin/manzokukyo-preview/`
- 既存入口: `/zannenin/manzokukyo/`
- 扉の移動先: `/zannenin/manzokukyo/truth/`（既存ページを使用）

入口だけの比較用ページ。回廊・オブジェ・扉はThree.jsで描画する。
一枚絵の回廊は使用しない。既存のBGMと、額の中の紹介画像・アニメ画像を再利用する。
文章・オブジェは試作で、公式設定の追加ではない。
検索結果には載せない設定とし、サイトマップには追加していない。旧ティザーの右上に「新ティザーを試す（仮）」のリンクを設置している。

対象ページのみ生成:

```powershell
node scripts/build-manzokukyo-preview.mjs
```

通常のサイトビルドにも組み込み済み。出力先は `dist/zannenin/manzokukyo-preview/`。
生成物は直接編集しない。

- 最初に音あり／音なしを選ぶ。音ありの場合だけBGM・効果音を有効化する。
- BGMと効果音の音量は個別に調整できる。別タブへの移動時は停止する。
- 映写機 → キュート版アニメティザー、交信機 → X、肖像 → 紹介ページ。各リンクは新しいタブで開く。
- 縦型スクリーン → TikTok、ゲーム機 → ゲーム・アプリの選択画面。ゲームの各リンクも新しいタブで開く。
- TikTokの入口画像は、ユーザー提供の `ComfyUI_00178_.png` を `assets/tiktok-entry.png` として保存。3:4の画像全体を表示し、顔やピースを切り抜かない。
- TikTokとゲーム一覧は `character.json` からビルド時に読み込む。ゲームは既存サイトと同じ分類条件で集め、公式・ファンゲーム・アプリの区分と提供済みの制作者名を表示する。
- 回廊は64m。5つのオブジェと扉への移動位置は `route.js` を共有し、画面下部のナビゲーションと一致させる。
- スクロール・スワイプで前後に歩く。下部の移動リンクから各オブジェへ直接移動できる。
- 明るさは維持し、床の真鍮の幾何紋、目に見える壁飾り、ゆっくり規則的に揺れる灯りで控えめな不穏さを加える。試作の演出であり、公式の紋章や設定ではない。
- 画面上部中央に「あしあと帳」を常設。既存サイトと同じ `zannenin:guestbook` を開き、投稿・お絵描き・履歴の仕組みを共有する。開いている間は回廊を止め、背景の操作を無効化し、フォーカスを帳内に保つ。
- 足音は距離と時間で間隔を制御し、開扉音は立体の扉の動きに合わせる。
- 動きの軽減設定では視点の揺れや常時アニメーションを止め、扉の移動待ちも短縮する。
- JavaScript/WebGL無効時もリンク一覧と扉のリンクは利用できる。
- 効果音9種は `sounds/` のオリジナル合成WAV。録音素材ではない。生成スクリプトと実測値を同梱。
- `vendor/` はThree.js 0.185.1（MIT）。ライセンスを同梱し、CDNに依存しない。
- ブラウザが対応する場合、回廊状態の読み取り、オブジェへの移動、あしあと帳の開閉をWebMCPで提供する。音声許可やあしあと帳への投稿を自動で行う操作は提供しない。
