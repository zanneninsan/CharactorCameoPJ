# 満足教ティザー・回廊と真理の扉の仮案

- 確認URL: `/zannenin/manzokukyo-preview/`
- 既存入口: `/zannenin/manzokukyo/`
- 扉の移動先: `/zannenin/manzokukyo-preview/truth/`（3D版の真理の扉）
- 合言葉の正解後: `/zannenin/manzokukyo/truth/gallery/`（既存の記憶の画廊）

回廊と、その先にある真理の扉の比較用ページ。室内・オブジェ・扉はThree.jsで描画する。
一枚絵の回廊は使用しない。既存のBGMと、額の中の紹介画像・アニメ画像を再利用する。
文章・オブジェは試作で、公式設定の追加ではない。
検索結果には載せない設定とし、サイトマップには追加していない。旧ティザーの右上に「新ティザーを試す（仮）」のリンクを設置している。

対象ページのみ生成:

```powershell
node scripts/build-manzokukyo-preview.mjs
```

通常のサイトビルドにも組み込み済み。出力先は `dist/zannenin/manzokukyo-preview/`。
生成物は直接編集しない。

- 最初に音あり／音なしを選ぶ。音ありの場合だけBGM・効果音を有効化する。
- BGMと効果音の音量は個別に調整できる。別タブへの移動時は停止する。
- 映写機 → キュート版アニメティザー、交信機 → X、肖像 → 紹介ページ。各リンクは新しいタブで開く。
- 縦型スクリーン → TikTok、ゲーム機 → ゲーム・アプリの選択画面。ゲームの各リンクも新しいタブで開く。
- TikTokの入口画像は、ユーザー提供の `ComfyUI_00178_.png` を `assets/tiktok-entry.png` として保存。3:4の画像全体を表示し、顔やピースを切り抜かない。
- TikTokとゲーム一覧は `character.json` からビルド時に読み込む。ゲームは既存サイトと同じ分類条件で集め、公式・ファンゲーム・アプリの区分と提供済みの制作者名を表示する。
- 回廊は64m。5つのオブジェと扉への移動位置は `route.js` を共有し、画面下部のナビゲーションと一致させる。
- スクロール・スワイプで前後に歩く。下部の移動リンクから各オブジェへ直接移動できる。
- 明るさは維持し、床の真鍮の幾何紋、目に見える壁飾り、ゆっくり規則的に揺れる灯りで控えめな不穏さを加える。試作の演出であり、公式の紋章や設定ではない。
- 壁の目は1.65倍の大きさにし、広い可動域で訪問者を追いながら左右・上下を見回す。スマホでも自動で視線が動き、目ごとに約4〜6秒おきにまばたきする。あしあと帳・お布施画面・別タブ表示中は目の時間も止め、動きの軽減設定では開いたまま静止する。
- 画面上部中央に「あしあと帳」を常設。既存サイトと同じ `zannenin:guestbook` を開き、投稿・お絵描き・履歴の仕組みを共有する。開いている間は回廊を止め、背景の操作を無効化し、フォーカスを帳内に保つ。
- 入口・音の案内・奥の扉に、アニメティザーと同じ `manzokukyo-emblem-v2.png` を使用する。透過と縦横比を維持する。
- 05の肖像の額は元の左側位置に置き、額の中の横顔だけを幅の12%ぶん右に寄せる。元画像の右余白を使い、顔や髪を切らずに左側の余白を広げる。向かいにはお布施箱を置く。
- お布施箱と末尾のボタンから「お布施ごっこ」を開ける。0円・5円・100円・1,000円・10,000円・1,000,000円・100,000,000円ごとにネタの称号と反応を表示し、選択・投入・結果・開閉に効果音を使う。実際のお金はかからず、通信・決済・金額の保存は行わない。閉じる／やり直すと再び遊べる。画面を開いている間は回廊を止める。
- お布施画面は黒金の枠に珊瑚色・青緑・紫を配したミニ舞台。金額選択で一言と色が変わり、投入後は0円の気まずい間、小銭・紙幣の投入、称号スタンプ、祝福や石油王の紙吹雪へ進む。専用の合成SE5種を音の許可・音量に従って再生し、画面内でも音を切り替えられる。演出中も閉じられ、閉じる／別タブへの移動で演出音を止める。動きの軽減設定では待ち時間とアニメーションを省く。
- 足音は距離と時間で間隔を制御し、開扉音は立体の扉の動きに合わせる。
- 動きの軽減設定では視点の揺れや常時アニメーションを止め、扉の移動待ちも短縮する。
- JavaScript/WebGL無効時もリンク一覧と扉のリンクは利用できる。
- 効果音は回廊9種＋お布施5種＋真理の扉1種の計15種。`sounds/` のオリジナル合成WAVで、録音素材ではない。生成スクリプトと実測値を同梱。
- `vendor/` はThree.js 0.185.1（MIT）。ライセンスを同梱し、CDNに依存しない。
- ブラウザが対応する場合、回廊状態の読み取り、オブジェへの移動、あしあと帳の開閉、お布施ごっこの開閉・金額選択と反応表示をWebMCPで提供する。音声許可やあしあと帳への投稿を自動で行う操作は提供しない。

## 真理の扉

- `truth/` に石造りの室内、真鍮の環と中央の目、二つの印を持つ祭壇、蝶番で開く両開きの扉を配置する。既存のエンブレムを再利用し、青緑と珊瑚色の灯りを添える。
- 印の石、または画面のボタンに触れて文字を送る。直接入力も可能。既存と同じ「満足」「まんぞく」を受け付け、空白を無視する。拒否回数の表示は3までで、試行回数を制限しない。
- 不正解では中央の目が大きく見開き、瞳をこちらに固定して素早く迫る。約0.6秒まで睨み、2.8秒かけて退く。環と吊り材も追従し、珊瑚色の灯りと周辺の陰影が強まる。3回までは少しずつ圧が増し、連打時も現在位置から動きをつなぐ。スマホでは拡大幅を抑えて目を画面内に収める。
- 入力や印の操作を再開しても目は自然に退き、正解時には開扉を優先する。正解では両開きの扉が開いて視点が奥へ進み、既存の記憶の画廊へ移る。回廊への戻りリンクも設ける。
- 音はこの部屋で明示的にオンにしたときだけ再生する。BGMと印・開扉の効果音は回廊の素材を共有し、不正解には専用の低い打撃と金属・息の共鳴音 `truth-denied.wav` を使う。音量を別々に調整でき、連打・正解・あしあと帳・別タブ移動では前の拒否音を中止する。
- あしあと帳を常設し、開いている間や別タブ表示中は室内と拒否演出の時計を止める。動きの軽減設定では接近・拡大・常時アニメーションと長い遷移を省き、静止した開眼と色で拒否を示す。WebGLが使えなくても合言葉の仕掛けは操作できる。
- WebMCPでは状態の読み取り、印の送り、合言葉の送信、あしあと帳の開閉を提供する。合言葉の送信は正解すると画廊へ移動することを説明に明記し、音の許可と投稿は自動化しない。
